# Todo Application Testing

This directory contains resources for testing the Todo application, including both manual and automated tests.

## Manual Testing

The manual tests are designed to verify all features of the Todo application through user interaction. They cover all core functionality required by the Business Requirements Document.

### How to Perform Manual Tests:

1. Open the application in a web browser
2. Follow the test cases in `manual/test_checklist.md`
3. Record your results using the template in `manual/test_results_template.md`
4. Save your completed test results in the `manual` directory with the filename format: `test_results_YYYY-MM-DD.md`
