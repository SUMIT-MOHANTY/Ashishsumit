# Todo Application

![Todo App Banner](https://via.placeholder.com/800x200?text=Todo+Application)

## Project Overview

This Todo Application is a dynamic, interactive web application built with Flask and enhanced with client-side JavaScript. It allows users to create, read, update, and delete todo items with a responsive, user-friendly interface. The application leverages asynchronous JavaScript to provide immediate feedback and a smooth user experience without page reloads.

### Key Features
- Create new todo items
- Mark todos as complete/incomplete
- Edit existing todos
- Delete unwanted todos
- Real-time feedback with notifications
- No page refreshes for common actions
