# Todo Application

## Project Overview

This Todo application is a full-stack web application built with React on the frontend and FastAPI on the backend. It allows users to create, read, update, and delete todo items, helping them stay organized and keep track of their tasks.

The application features a clean, intuitive user interface with responsive design for both desktop and mobile use. Todos can be marked as complete, edited, and filtered by status (all, active, completed).

## Tech Stack

### Frontend
- React.js
- TypeScript
- React Router for navigation
- Tailwind CSS for styling
- Axios for API requests

### Backend
- FastAPI (Python)
- SQLite database
- Pydantic for data validation
- SQLAlchemy for ORM
